# 01: App shell

**What to build:** A development build of the app that launches on the iOS simulator and the Android emulator, in portrait and landscape, and shows the Movie List screen's "Watch" header inside the root native stack, styled with NativeWind in the Figma palette and Poppins. It proves the platform decisions (ADR-0002, ADR-0004) and the styling stack before any feature work.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Expo SDK 55 project in TypeScript strict mode on the New Architecture, with iOS deployment target 15.1 and Android minSdk 24 / targetSdk 36. Libraries are added with `npx expo install` so versions follow SDK 55's pinned set.
- [x] Native projects are generated by prebuild and gitignored; orientation, fonts and other native settings live in the app config and config plugins.
- [x] The app runs as a development build on the iOS simulator and the Android emulator, rotates freely on both, and respects safe-area insets (Android edge-to-edge is always on).
- [x] NativeWind renders on both platforms. The Tailwind config holds the Figma palette, a spacing scale, and Poppins with one font family per weight, embedded at build time with the expo-font config plugin.
- [x] If NativeWind can't work with SDK 55, the fallback is `StyleSheet` with the same design values, recorded in an ADR with the reason.
- [x] React Navigation 7 native stack with a typed root param list; Movie List is the initial route and shows the "Watch" header. No search button yet (ticket 08 adds it), so nothing on screen is dead.
- [x] Text and Screen primitives own their class strings.
- [x] The TMDb token is read from `EXPO_PUBLIC_TMDB_TOKEN`; `.env.example` is committed, `.env` stays gitignored, and a missing token fails with a clear developer-facing message instead of an obscure request error.
- [x] A README stub covers install, `.env` and running on iOS and Android.

## Comments

**2026-09-30, implementation notes**

- Figma palette: the agent's browser couldn't open the Figma link, so the colours come from the Figma "Guide" frame screenshot shared during planning. Each swatch was sampled and matched to the Figma hex values within ±3 per channel (drift from the screenshot's compression and colour profile). The screens also use two text colours the guide doesn't list, added as `ink` (#202C43, headings) and `muted` (#8F8F8F, body copy). Worth a spot-check in Figma Dev Mode.
- Chosen with the user in this session: NativeWind 4.2.7 (stable) over 5.0.0-rc.0; Poppins TTFs committed under `assets/fonts`, named by PostScript name with the OFL licence, rather than the `@expo-google-fonts/poppins` package; app name "TMDb Movies" with id `com.rasikhqadeer.tmdbmovies`; `expo-system-ui`, so Android honours the light-only `userInterfaceStyle`.
- `expo-build-properties` pins iOS 15.1 and Android min 24 / compile 36 / target 36 in `app.json`, so the platform floor is visible in the repo even though the native projects are gitignored.
- Screens hide the native stack header and draw the Figma header in the Screen primitive: native-stack can't left-align a custom-font title on iOS.
- NativeWind's rem is set to 16 and the spacing and type scales are in px, so class names mean the same sizes as web Tailwind.
- The StyleSheet fallback wasn't needed, so there's no ADR.
- Code review found that `npm start` opened Expo Go, so `expo-dev-client` was added (chosen with the user). The debug builds are now Expo development builds, and `npm start` with `i` or `a` opens them.
- `readTmdbToken()` has no caller yet. Ticket 03's API client is its first user, and should turn the plain `Error` it throws into the typed "token missing or invalid" error. Checked in Node: missing or blank throws the setup message; a set value comes back trimmed.
- No tests in this ticket. Jest arrives with ticket 02, whose first behaviour test covers "opens on Movie List and shows Watch".
- Verified: `tsc --noEmit`, `expo-doctor` (20/20), and development builds on the iPhone 17 Pro simulator (iOS 26.5) and the Pixel 9 Pro emulator (API 35), each in portrait and landscape.
- Not verified: the iOS 18.5 simulator (iPhone 16 Pro). `simctl boot` failed with "Invalid argument" and the install hung, so only iOS 26.5 was checked. Ticket 13's README claims both, so retry there.
