# 01: App shell

**What to build:** A development build of the app that launches on the iOS simulator and the Android emulator, in portrait and landscape, and shows the Movie List screen's "Watch" header inside the root native stack, styled with NativeWind in the Figma palette and Poppins. It proves the platform decisions (ADR-0002, ADR-0004) and the styling stack before any feature work.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Expo SDK 55 project in TypeScript strict mode on the New Architecture, with iOS deployment target 15.1 and Android minSdk 24 / targetSdk 36. Libraries are added with `npx expo install` so versions follow SDK 55's pinned set.
- [ ] Native projects are generated by prebuild and gitignored; orientation, fonts and other native settings live in the app config and config plugins.
- [ ] The app runs as a development build on the iOS simulator and the Android emulator, rotates freely on both, and respects safe-area insets (Android edge-to-edge is always on).
- [ ] NativeWind renders on both platforms. The Tailwind config holds the Figma palette, a spacing scale, and Poppins with one font family per weight, embedded at build time with the expo-font config plugin.
- [ ] If NativeWind can't work with SDK 55, the fallback is `StyleSheet` with the same design values, recorded in an ADR with the reason.
- [ ] React Navigation 7 native stack with a typed root param list; Movie List is the initial route and shows the "Watch" header. No search button yet (ticket 08 adds it), so nothing on screen is dead.
- [ ] Text and Screen primitives own their class strings.
- [ ] The TMDb token is read from `EXPO_PUBLIC_TMDB_TOKEN`; `.env.example` is committed, `.env` stays gitignored, and a missing token fails with a clear developer-facing message instead of an obscure request error.
- [ ] A README stub covers install, `.env` and running on iOS and Android.
